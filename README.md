# AI DevOps Platform

An end-to-end DevOps portfolio project that demonstrates how modern applications are built, tested, deployed, monitored, and automatically recovered.

## Project Goal

The goal of this project is to build a production-style DevOps platform using tools and practices used in real companies.

## Planned Features

* Demo web application
* Docker containerization
* GitHub Actions CI/CD
* Automated testing
* Security scanning
* Kubernetes deployment
* Prometheus monitoring
* Grafana dashboards
* Centralized logging
* Alerting
* n8n incident automation
* AI-assisted root cause analysis
* Infrastructure as Code with Terraform

## Project Structure

* `app/` — Demo application
* `docker/` — Docker configuration
* `kubernetes/` — Kubernetes manifests
* `monitoring/` — Monitoring and alerting configuration
* `automation/` — n8n workflows
* `infrastructure/` — Terraform and infrastructure files
* `docs/` — Project documentation and diagrams
* `scripts/` — Helper scripts
* `.github/workflows/` — CI/CD pipelines
